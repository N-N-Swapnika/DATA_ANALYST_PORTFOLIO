# SwapCart Customer Analysis - SQL Case Study

## Project Overview
This project uses MySQL to analyze customer spending patterns and customer distribution across different cities for an e-commerce business.

## Objectives
- Analyze customer distribution across cities.
- Calculate customer spending patterns.
- Identify high-spending customers.
- Apply SQL clauses to answer business questions.

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- Aggregate Functions
- HAVING
- ORDER BY
- LIMIT
- CASE Expressions

## Tools Used
- MySQL
- MySQL Workbench

## Project Files
- swapcart_customer_analysis.sql - Contains SQL queries used to perform customer analysis.
- README.md - Project documentation, objectives and analysis overview.

## Learning Outcome
Through this case study, I gained practical experience in:
- Retrieving and filtering customer records using SELECT and WHERE.
- Grouping customer data using GROUP BY.
- Applying aggregate functions to calculate customer statistics and spending.
- Filtering grouped results using HAVING.
- Sorting and limiting query results.
- Applying conditional logic using CASE expressions.
- Translating business questions into SQL queries.

## Conclusion
This project helped me apply fundamental SQL concepts to a business-oriented customer analysis problem. It strengthened my understanding of SQL query writing and my ability to use data to answer business questions.
