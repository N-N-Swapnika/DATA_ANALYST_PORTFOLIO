# SwapCart Customer Analysis - SQL Case Study

## Project Overview
This is my first SQL case study using MySQL.

SwapCart is an e-commerce company interested in understanding customer spending patterns across cities.

## Objectives
- Analyze customer distribution across cities.
- Calculate customer spending patterns.
- Identify high-spending customers.
- Apply SQL clauses to answer business questions.

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- Aggregate Functions
- HAVING
- ORDER BY
- LIMIT
- CASE

## Tools Used
- MySQL
- MySQL Workbench

## Project Files
- swapcart_customer_analysis.sql

## Learning Outcome
Applied fundamental SQL clauses to solve business-related questions using customer data.
